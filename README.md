# Payments Manager — Roadmap do Produto

Painel local do roadmap Payments Manager, SOS Docs / SmartDocs. O `index.html` carrega os estilos em `style.css`, os dados e interações em `app.js`, o logo SmartDocs em `smartdocs-logo.svg` e o logo SOS Docs pelo endereço oficial informado.

## Abas
- Visão geral
- Roadmap de sprints (R1–R11), com filtro por fase
- Métricas e capacidade, com gráficos de planejamento derivados do roadmap
- Homologação regulatória
- Segurança e operação
- Documentação, contratos e jurídico
- BASA e prontidão

O roadmap contém 167 histórias e 924 SP planejados: F0 + MVP (R1–R9, 141 histórias, 770 SP) e F2 (R10–R11, 26 histórias, 154 SP). Gráficos não representam execução real. As atividades de homologação correm em paralelo e permanecem fora dos story points; a visualização é somente leitura.

Para abrir, carregue `index.html` em um navegador moderno.
